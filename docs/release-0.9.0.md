# 0.9.0 公开前说明

本项目的技能、默认工作流和安装脚本面向 **Codex**。其他 AI harness 需要自行适配技能加载、本地执行、权限和路径，并独立完成端到端验证。当前工作仅准备公开，未授权发布或改变仓库可见性。

## 本次变更

- 原生保存兼容：支持本次 AT89C51RD2 实例观察到的 2048 字节全零实体扩展，并原样保留；不推断其用途。未知长度、非零内容、其他未经验证型号仍拒绝。Python 不能读回时，技能提供保留原件、独立原生重开和 SDF 比较流程，不能据此重写未知结构。
- 运行截图：新增 `Simulation.capture()`，默认 `foreground=True`，重设原生定时目标，要求截图前后实际计时推进，核对自有窗口真实主画布，最后暂停。WTS 检出锁定/断开或画布单色时拒绝；只截取本次自有进程窗口。PNG 与相邻 JSON 保留范围和失败原因。
- 状态读取：绑定首次唯一主状态栏身份，避免 VSM 调试器新增同编号控件后选错；每次仍核对 PID 和原生指针身份，不缓存状态或时间。
- 编辑器菜单：`Session.menu()` 对唯一匹配但暂时禁用的已识别命令默认等待最多 15 秒，再取新鲜主窗、进程、菜单和命令 ID；缺失、歧义或身份/配置变化立即拒绝。该等待不等同于仿真或命令完成，未改低层 codec 和 `Simulation._command`。
- 原生日志：按真实自有父/所有者链区分 VSM Debugger 内嵌日志与自定义类的独立 Simulation Log，核对 PID、层级、签名和唯一性；不假设标准 `#32770` 对话框。三个失败原生副本实际读出了 SPICE 初始化错误；后来正常独立窗口读取也已通过，诊断为零错误、零警告。
- PP 电源边界：本例 AT89C51RD2/DIL40 的 VCC40/GND20 由原生 PP 声明自动绑定，生成器不再重复加显式端子。逻辑视图依据选中 PACKAGE 和完整引脚映射归并，全 29 个期望网络保留，物理显式视图不变。示例电容另明确为 `DEVICE/CAP`，不将这一调整写成已定位的 SPICE 根因。
- 数字助手：每组最多五个二态按键的副本准备/原生分组执行，严格段码解码及多位扫描帧重建。每次输入要求原生 STATE 回读，每个用例要求实际计时推进；显示报告保留采样窗口，至少两轮完整覆盖结果一致。
- 独立例程：8051、4×4 矩阵键盘与八位数码管，普通 32 元件、带探针 48 元件。示例固件增加可观测响应计数，并可由项目自有的受限纯 Python 8051 汇编器独立重建。
- 技能与安装：主技能收敛为当前流程和按需参考；单位、方向、布线排错与返回结构集中。安装复制全部参考资源，显式 `--update` 才更换已有树，核对可恢复备份，保留用户无关配置，备份位于自动扫描技能目录之外。

## 使用与限制

新示例的固件重建和生成：

```powershell
python examples/build_matrix_firmware.py --output-dir output/matrix_firmware_new --check-against examples/matrix_display.hex
python examples/draw_matrix_display.py --output-dir output/matrix_display_new --firmware output/matrix_firmware_new/matrix_display.hex --probes
```

汇编器只支持该独立示例需要的严格语法，见 [构建说明](../examples/matrix_firmware_build.md)。文件/固件可复现、原生保存可读、计时推进、数字功能断言和视觉截图分别报告。重建的显示帧跨扫描相位，不是八位输出的瞬时原子采集；采样可漏掉间隔中的变化。`observe()` 返回 `simulation_seconds`，`actual_at` 属于场景样本。五控件限制未被分组助手消除。

PCB 布线、任意电压/连续波形、通用模型内存、嵌入式 VSM Studio 构建和实物硬件验证仍不支持。截图需要解锁的交互桌面与 Pillow；常规文件 API 使用标准库。游戏期间仅做文件工作，不启动原生检查；清理仅针对本次自有进程。
