# Local template (not distributed)

Open your own installed Proteus 8.6 official Rescap sample, save a new local copy,
and set PROTEUS86_TEMPLATE to it. Alternatively put your compatible copy at
templates/base86.pdsprj. The tool validates the known format and refuses unknown
structures. Do not modify version headers or overwrite official samples.

Proteus binaries, models and template definitions are governed by their own
licenses and are intentionally excluded from this source repository.
